## Descripción larga

**Deja de acumular pestañas. Empieza a trabajar con confianza.**

TabTaskTick es un gestor de pestañas con una lista de tareas integrada. Guarda ventanas enteras, adjunta tareas y notas a las pestañas en las que realmente estás trabajando, pospón lo que no necesitas ahora y deja que las reglas mantengan el orden — todo se almacena localmente en tu navegador. Sin cuenta. Sin nube. Sin seguimiento.

### Para quién es

*   **Investigadores** que manejan más de 100 pestañas y no pueden permitirse perder una fuente.
*   **Desarrolladores** que cambian de contexto entre proyectos todo el día.
*   **Practicantes de GTD** que mantienen una revisión semanal real.

---

### 📁 Cerrar una ventana no debería significar perder el trabajo que hay dentro.
Las **Colecciones** guardan una ventana entera — URLs, notas y tareas — como un espacio de trabajo con nombre.
*   **Restauración con un clic** trae de vuelta un proyecto completo exactamente como lo dejaste.
*   **Contexto preservado**, no solo marcadores: las notas y tareas también vuelven.
*   **Compartible** — exporta una Colección para entregar a un colega tu paquete de investigación.
*   Cierra ventanas con tranquilidad. Todo está seguro en tu base de datos local.

### ✓ Has estado usando las pestañas como lista de tareas. Son terribles para eso.
Las **Tareas y Notas** te permiten adjuntar to-dos reales y contexto a una pestaña o a toda una Colección — para que tres semanas después aún sepas *por qué* la guardaste.
*   **Tablero Kanban** en el panel lateral para ver todo lo que está en marcha.
*   Tus to-dos viven donde vive el trabajo, con la URL todavía adjunta.

### 🤖 Tu navegador no debería necesitar una niñera.
El **motor de reglas** mantiene el orden automáticamente.
*   **Agrupación automática** por dominio o criterios personalizados.
*   **Eliminación de duplicados** — encuentra y cierra pestañas duplicadas, de forma global o por ventana.
*   **Posposición inteligente** — haz desaparecer una pestaña o una ventana entera ahora y que vuelva más tarde ("posponer hasta mañana por la mañana").
*   **Suspensión de memoria** de pestañas inactivas para mantener Chrome rápido.

### 📊 ¿200 pestañas en 5 ventanas? Velo todo a la vez.
El **panel** te da la vista a vista de pájaro.
*   Estadísticas generales, dominios principales y un historial buscable de pestañas cerradas.
*   Acciones masivas — selecciona, mueve, cierra o agrupa pestañas en todas las ventanas a la vez.

### 💾 Nunca vuelvas a perder una sesión.
*   Exporta tu sesión completa o una sola ventana a **JSON, CSV o Markdown**.
*   **Copias de seguridad programadas** con política de retención.
*   Restaura una ventana o todo desde cualquier archivo de copia de seguridad.

### 🛡️ Por qué importa que sea solo local

La queja más común sobre los gestores de pestañas en la nube es: "Me obligaron a crear una cuenta, y ahora mis datos son rehenes." TabTaskTick está construido al revés.

| | **TabTaskTick** | Toby / Workona |
|---|---|---|
| Dónde viven tus datos | Tu navegador (local) | Su nube |
| Cuenta obligatoria | No | Sí |
| Funciona sin conexión | Sí | Limitado |
| Seguimiento | Ninguno | Analytics |
| Código abierto | Sí (MIT) | No |
| Precio | Gratis | Freemium / muro de pago |

Todos los datos — Colecciones, Tareas, Reglas, historial — se almacenan localmente en tu navegador (IndexedDB). Nunca los enviamos a ningún sitio.

---

### ⌨️ Atajos de teclado

Aquí viven los power users:
*   **Ctrl/Cmd + Mayús + S** — posponer rápido la pestaña actual
*   **Ctrl/Cmd + Mayús + G** — agrupar todas las pestañas por dominio
*   **Ctrl/Cmd + Mayús + D** — cerrar pestañas duplicadas

Reasígnalos en `chrome://extensions/shortcuts`.
